---
name: "create-project"
description: "Actions to take when initializing a project from scratch."
---
Run `git init`, `gh repo create --private`, `mkdir desks/`, `mkdir .worktrees/`, `memo init`, `echo '.worktrees' > .gitignore`, `echo '...' > README.md` (keep it succinct and high signal-to-noise; don't overdo it), and `touch AGENTS.md`. Then stage, commit, and push.

This does not cover software development setup.
