name: "herdr"
description: "What is herdr and how to use it."
---
herdr is like tmux that understand CLI AI agents. Run `herdr --skill` for a good entrypoint. Dive in to more specific subcommand by running `helpall herdr <subcommand>`.

`scripts/boomerang.sh` asynchronously prompts the current Pi session, with optional `--before` and `--after` Bash hooks.
